# Prompts for the FRP literature review

The prompts that produced and checked
[the review](../2026-09-28-frp-literature-review.md), as its agents got
them. Its [handoff](../handoff-2026-09-27-frp-literature-review.md)
says when each was used.

- `reading/briefing.md`: the brief every phase 3 reading agent got.
- `verify/brief.md`: the brief every verifier got, with
  `verify/claims-task.md` for the seven claims slices and
  `verify/probes-task.md` for the probe re-runs.

Paths outside this repo are placeholders:

- `<rfd>`: this repo, in the worktree the review ran in.
- `<literature>`: the private literature corpus.
- `<experiments>`: the probes' repository, which the review's header
  names.
- `<scratch>`: a scratch directory outside every repo, not kept.
- `<sodium-book>`: a private markdown copy of the Sodium book, which the
  review cites by chapter.
